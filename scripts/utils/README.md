# Utils Scripts

Este diretório agrupa utilitários manuais de diagnóstico que não pertencem a um subprojeto específico.

## Conteúdo

- `check_chars.js`: utilitário legado para inspecionar char codes de linhas específicas em um arquivo alvo.

## Observação

Alguns scripts aqui podem depender de caminhos locais ou arquivos antigos do workspace. Trate-os como utilitários manuais, não como runbooks operacionais estáveis.
