Como importar tokens no Figma

  1. No Figma, instale o plugin Tokens Studio for Figma (gratuito)
  2. Abra o plugin → Import from JSON → selecione docs/design-system/figma-tokens.json
  3. Tokens serão importados como Variables com modos Light e Dark
  4. Crie Text Styles seguindo a tabela de Tipografia
  5. Crie componentes usando Auto Layout com spacing tokens
  6. Nomeie camadas com PascalCase (ProductCard, OrderBadge)
  7. Use Component Properties para variant/size/state
