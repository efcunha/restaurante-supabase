# Repository Docs

Este diretório agrupa documentação estrutural do monorepo, separada de runbooks operacionais e de documentos de segurança.

## Conteúdo

- `DOMAINS.md`: mapa conceitual dos domínios do repositório
- `SCRIPTS_INVENTORY.md`: inventário estrutural e inconsistências conhecidas de scripts
- `FORM_AUTOMATION_SEMI_AUTO_RUNBOOK.md`: runbook operacional da automação semi-automática segura de formulários
- `HANDOFF_D1_POS_DEVICE_BINDINGS_2026-04-14.md`: handoff operacional consolidado (migration, RLS smoke, evidências e retomada)
- `PR_DESCRIPTION_POS_DEVICE_BINDINGS_2026-04-14.md`: descrição de PR pronta para uso (escopo, segurança, evidências e riscos)
- `PARECER_PRODUCAO_POS_DEVICE_BINDINGS_2026-04-14.md`: decisão formal GO/NO-GO para escopo atual e pendências de fechamento total
- `AWESOME_COPILOT_INTEGRATION_2026-04-20.md`: instalação, precedência e cruzamento do awesome-copilot com as skills locais
- `AWESOME_COPILOT_SQUAD_MATRIX_2026-04-20.md`: matriz de uso por squad (app, web, ops) com roteamento recomendado de skills/plugins
