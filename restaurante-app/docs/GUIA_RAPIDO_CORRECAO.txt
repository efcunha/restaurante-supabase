================================================================================
                    GUIA RÁPIDO - CORREÇÃO DO ÍCONE CORTADO
================================================================================

PROBLEMA: O ícone está sendo cortado nas bordas quando exibido no Android

CAUSA: Adaptive Icons do Android usam apenas 66% da área central da imagem

SOLUÇÃO: Adicionar padding automático ao ícone

================================================================================
                         COMANDO ÚNICO (MAIS FÁCIL)
================================================================================

Execute este comando para corrigir tudo automaticamente:

    cd restaurante-app
    npm run update-icon

Este comando faz:
  1. ✅ Adiciona padding ao ícone (usando icone-bak.png)
  2. ✅ Gera todos os ícones Android em 5 densidades
  3. ✅ Remove arquivos antigos

================================================================================
                         APLICAR NO CELULAR
================================================================================

Após executar o comando acima, reconstrua o app:

    cd android
    ./gradlew clean
    cd ..
    npx expo run:android

================================================================================
                         O QUE FOI FEITO
================================================================================

1. BACKUP DA IMAGEM ORIGINAL
   ✅ icone-bak.png = imagem original (sem alterações)

2. SCRIPT DE CORREÇÃO
   ✅ fix-icon-padding.js = adiciona padding automático

3. NOVO COMANDO NPM
   ✅ npm run fix-icon-padding = corrige o padding
   ✅ npm run update-icon = corrige + gera ícones (tudo de uma vez)
