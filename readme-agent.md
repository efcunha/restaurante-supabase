# 🦑 Agente Antigravity

Bem-vindo(a) ao seu espaço de trabalho governado pelo Squidy.
Este arquivo é o ponto de entrada principal para qualquer sessão de IA neste repositório.

## 🎯 Initialization Ritual

Sempre que você (agente) iniciar uma nova conversa ou retomar o contexto após reiniciar, você DEVE executar este ritual:

1. **Leia a Constituição e o Oráculo do Projeto**:
   - `squidy/docs/Constitution.md`: Regras de Ouro e Proibições.
   - `squidy/docs/Oracle.md`: Conhecimento do domínio.
   - Entenda a sua [Identidade do Agente (AGENT.md)](squidy/docs/AGENT.md).

2. **Leia o Contexto Atual**:
   - Analise o `squidy/docs/contexto-sessao.md` para carregar a Tabela de Decisão, Restrições e Histórico Recente.

3. **Verifique as Políticas e o Kanban**:
   - Leia `squidy/docs/politicas.md` para entender as regras de code review e commit.
   - Leia os impedimentos em `squidy/docs/emergencia.md`.
   - Consulte o quadro e as prioridades atuais em `squidy/boards/kanban.md`.

4. **Registre sua Chegada**:
   - Adicione uma entrada rápida confirmando a leitura e a compreensão do contexto na sessão diária atual (em `squidy/diario/`).
